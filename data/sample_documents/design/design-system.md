# Product Design System

ACME interfaces use shared color, typography, spacing, form, and navigation components. Designers
should begin with the maintained component library before creating a new pattern. New components need
documented states for loading, empty results, errors, disabled actions, keyboard focus, and small
screens.

Accessibility is part of completion, not a later review. Text and controls require sufficient contrast,
interactive elements need visible focus, and workflows must work with a keyboard. Content uses direct
language and explains how a user can recover from an error. A component moves from proposal to stable
only after design and engineering review. Deprecated patterns remain documented with a replacement and
migration date so products do not silently diverge.
